
#  Uganda Economic Dashboard

An interactive data visualization dashboard that analyzes and presents Uganda’s economic indicators using Python-based data science tools.

## Features

- Interactive charts for economic trends
- Data filtering and exploration
- Visual representation of key indicators
- Clean dashboard layout for insights
- Supports CSV-based datasets

## Problem It Solves

Economic data is often complex and difficult to interpret.  
This dashboard simplifies analysis by transforming raw data into clear visual insights.

## Tech Stack

- Python
- Pandas
- Plotly / Matplotlib
- Dash
- CSV datasets
- Git & GitHub

## Key Visualizations

- GDP trends over time
- Inflation analysis
- Economic comparisons
- Data summaries and KPIs
